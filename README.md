# construction-estimate-frontend

Фронтенд для курсовой по РИП: справочник строительных работ для расчета бюджета постройки с учетом исторических цен.

React + TypeScript + Vite + React-Bootstrap. Пока работает только на mock-данных (`src/modules/mock.ts`), без бэкенда.

## Запуск

```
npm install
npm run dev
```

Открывается на http://localhost:3000

## Страницы

Внизу панель: Лента, Добавление, Плитка, Вход. Сейчас работают только Лента и Плитка, Добавление и Вход появятся позже.

**Плитка** (`/`) - все работы карточками в две колонки.
- ползунок "Цена до" - максимальная цена в копейках
- кнопка "Найти" - оставляет работы не дороже выбранной цены
- карточка - фото, название, цена, год и лайки, по нажатию открывается в ленте

**Лента** (`/feed/:id`) - одна работа на весь экран.
- на фоне видео работы
- справа лайки, цена, год цены и кнопка "Следующий" (следующая работа из плитки)
- снизу название и описание, "... ещё" раскрывает описание целиком

Если у работы нет фото или видео, показываются `public/DefaultImage.png` и `public/DefaultVideo.mp4`.
