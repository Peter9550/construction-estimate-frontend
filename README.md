# construction-estimate-frontend

Фронтенд для курсовой по РИП: справочник строительных работ для расчета бюджета постройки с учетом исторических цен.

React + TypeScript + Vite + React-Bootstrap, состояние в Redux Toolkit, запросы через axios. Данные берутся из бэкенда `construction-estimate-backend`. Если бэкенд недоступен, гость видит работы из mock (`src/modules/mock.ts`).

## Запуск

```
npm install
npm run dev
```

Открывается на http://localhost:3000. Бэкенд должен работать на http://localhost:8000, MinIO на http://localhost:9000.

## Прокси

Браузер обращается только к http://localhost:3000, поэтому CORS не нужен. Vite пересылает запросы дальше (`vite.config.ts`):

- `/api/...` -> `http://localhost:8000/api/...` (веб-сервис);
- `/minio/...` -> `http://localhost:9000/...` (фото и видео из MinIO, адреса из БД переписывает `src/modules/media.ts`).

## Кодогенерация

Методы обращения к веб-сервису сгенерированы из Swagger бэкенда библиотекой `swagger-typescript-api`:

```
npm run generate-api
```

Скрипт `scripts/generate-api.mjs` берет схему с http://localhost:8000/openapi.json и пишет `src/api/Api.ts` (axios). Экземпляр клиента - `src/api/index.ts`.

## Состояние Redux

- `user` (`src/slices/userSlice.ts`) - логин и признак входа. Вход и выход идут обычным axios из страниц, результат кладется в Redux вручную.
- `constructionWorks` (`src/slices/constructionWorksSlice.ts`) - фильтр по цене, список работ, работа в ленте, черновик, признак загрузки и текст ошибки. Все запросы по работам - thunk на сгенерированных методах.

После F5 Redux начинается заново (гость), кука сессии `sessionId` в браузере остается.

## Страницы

Внизу панель: Лента, Добавление, Плитка, Вход. Добавление доступно только после входа, вместо Вход тогда показан Выход. Пока идет запрос, страница закрыта полупрозрачным слоем с анимацией, кнопки не нажимаются.

**Плитка** (`/`) - опубликованные работы карточками в две колонки.
- ползунок "Цена до" - максимальная цена в копейках, значение хранится в Redux и не сбрасывается при переходах
- кнопка "Найти" - запрос к бэкенду с параметром `max_historical_price`
- карточка - фото, название, цена, год и лайки, по нажатию открывается в ленте
- кнопка "Удалить" - только у своих работ вошедшего сметчика

**Лента** (`/feed/:id`) - одна работа на весь экран.
- на фоне видео работы
- справа лайк, цена, год цены и кнопка "Следующий"
- лайк нажимается только после входа, повторное нажатие снимает лайк
- снизу название и описание, "... ещё" раскрывает описание целиком

**Добавление** (`/add`) - создание работы в два шага.
- без черновика: выбор фото и видео (превью сразу на странице), поле "Название", кнопка "Далее" создает черновик
- с черновиком: фото и видео из MinIO, название текстом, поля "Краткое описание", "Цена, коп.", "Год цены", кнопка "Опубликовать" публикует и открывает работу в ленте

**Вход** (`/login`) - поля "Логин" и "Пароль", кнопка "Войти". При ошибке показывается текст под полями.

**Выход** - кнопка в панели: завершает сессию, сбрасывает фильтр и возвращает интерфейс гостя.

Если у работы нет фото или видео, показываются `public/DefaultImage.png` и `public/DefaultVideo.mp4`.
