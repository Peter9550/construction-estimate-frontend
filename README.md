# construction-estimate-frontend

Фронтенд заявочной системы "Расчёт бюджета создания постройки или
произведения с учётом исторического индекса цен".

Тема №26, раздел "История и культура".
Курс "Разработка интернет-приложений", ИУ5, 5 семестр.

Одностраничное приложение (SPA) к бэкенду construction-estimate-backend.
Интерфейс сделан под вертикальный экран телефона: на компьютере приложение
показывается колонкой шириной 390px по центру окна.

## Стек

- React 19, TypeScript
- Vite - сборщик и сервер для разработки
- react-router-dom - переходы между страницами без перезагрузки
- React-Bootstrap - компоненты интерфейса (Card, Button, Form.Range)

## Запуск

```
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`.

Сборка для публикации: `npm run build`, результат в папке `dist`.

## Данные

В лабораторной 5 бэкенд не используется. Карточки строятся только из
mock-объектов в `src/modules/mock.ts`: 8 опубликованных строительных работ с теми
же полями, что отдаёт метод `GET /api/construction-works` бэкенда
(`id`, `work_name`, `work_description`, `historical_price`, `base_year`,
`image_url`, `video_url`, `likes_count` и т.д.).

Фото и видео работ лежат в самом проекте, в папке `public/media`, и mock
ссылается на них (`/media/masonry.jpg`, `/media/masonry.mp4` и т.д.).
Хранилище MinIO в этой лабораторной не используется.

Если поле `image_url` или `video_url` пустое, показывается файл по умолчанию:

- `public/DefaultImage.png` - изображение по умолчанию;
- `public/DefaultVideo.mp4` - видео по умолчанию.

У работы "Подсобные работы" (id 7) оба поля пустые: на ней видно, как
срабатывают файлы по умолчанию.

## Страницы

### Нижняя панель вкладок

Есть на всех страницах, закреплена внизу экрана. Четыре пункта:

| Пункт | Что делает |
|---|---|
| Лента | Открывает ленту с первой работы из текущего списка. Доступен |
| Добавление | Недоступен: выглядит как остальные пункты, но не реагирует на нажатие. Страница появится в следующих лабораторных |
| Плитка | Открывает плитку. Доступен |
| Вход | Недоступен: выглядит как остальные пункты, но не реагирует на нажатие. Страница появится в следующих лабораторных |

Открытая вкладка подсвечивается красным.

### Плитка - `/`

Справочник строительных работ в виде плитки в две колонки.

Фильтр по цене:

| Элемент | Описание |
|---|---|
| Надпись "Цена до" | Справа выбранная граница цены в копейках |
| Ползунок | Граница цены. Минимум и максимум берутся из данных: от самой низкой до самой высокой цены (79 - 200 коп.) |
| Кнопка "Найти" | Оставляет в плитке работы, у которых цена не больше выбранной границы |

Если по фильтру ничего не найдено, выводится надпись "Работ с такой ценой не найдено".

Карточка работы:

| Элемент | Описание |
|---|---|
| Изображение | `image_url` работы, если поле пустое - изображение по умолчанию |
| Название | `work_name` |
| Цена и год | `historical_price` в копейках и `base_year` |
| Сердечко с числом | Количество лайков `likes_count` |

Нажатие на карточку открывает эту работу в ленте.

### Лента - `/feed/:id`

Одна работа на весь экран, как в коротких видео. `:id` - идентификатор работы.

| Элемент | Описание |
|---|---|
| Видео на фоне | `video_url` работы, если поле пустое - видео по умолчанию. Обложка до запуска - `image_url` или изображение по умолчанию |
| Сердечко с числом | Количество лайков |
| Блок "Цена" | Историческая цена в копейках |
| Блок "Год цены" | Год, к которому относится цена |
| Кнопка "Следующий" | Переход к следующей работе из текущего списка. После последней работы - снова первая |
| Название | `work_name` |
| Описание | Первые 70 символов (обрезка по последнему пробелу). Нажатие на "... ещё" показывает описание целиком |

Порядок работ в ленте совпадает с плиткой: если в плитке применён фильтр,
кнопка "Следующий" переходит только по отфильтрованным работам.

Если работы с таким `id` нет, выводится надпись "Работа не найдена".

## Структура кода

| Путь | Назначение |
|---|---|
| `src/main.tsx` | Точка входа: подключение Bootstrap и отрисовка `App` |
| `src/App.tsx` | Маршруты приложения |
| `src/Routes.tsx` | Адреса страниц и подписи пунктов панели вкладок |
| `src/AppLayout.tsx` | Общая оболочка: страница и панель вкладок. Хранит текущий список работ и передаёт его страницам через `Outlet context` |
| `src/components/TabBar.tsx` | Нижняя панель вкладок |
| `src/components/PriceFilter.tsx` | Фильтр по цене: ползунок и кнопка "Найти" |
| `src/components/WorkCard.tsx` | Карточка работы в плитке |
| `src/pages/CatalogPage.tsx` | Страница "Плитка" |
| `src/pages/FeedPage.tsx` | Страница "Лента" |
| `src/modules/constructionWorksApi.ts` | Тип `ConstructionWork` - объект работы, как его отдаёт бэкенд |
| `src/modules/mock.ts` | Mock-объекты работ |

## Ветки

Каждая лабораторная лежит в своей ветке.

- `main` - общая
- `construction_work_spa_mock` - лабораторная 5: SPA на mock-данных
